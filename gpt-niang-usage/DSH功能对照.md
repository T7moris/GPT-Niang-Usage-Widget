# DSH 0.3.17 功能核对

本表记录交互参考与本项目的实现范围。DSH 一栏来自 2026-10-01 对本机 `dsh-whale-widget` 0.3.17 副本的核对，包括 `assets/whale-widget.js`、默认角色图及相关设置；不能代表其他分支或后续版本。本项目一栏对应 GPT 娘 1.2.4。

| 项目 | DSH 实际行为 | GPT 娘 1.2.4 |
|---|---|---|
| 造型 | 大头半身静态 PNG，贴右/底边 | 白发龙娘的静态半身图；无嘴巴，采用类似构图 |
| 布局 | 方形容器，角色占约 59.45% | 方形容器，角色占约 59.45% |
| 呼吸/眨眼 | 默认 PNG 没有自动呼吸或眨眼 | 没有自动呼吸或眨眼 |
| 按压 | 横向 105%、纵向 88%，220ms 回弹 | 同比例和时长，使用同样的曲线控制点 |
| 气泡 | 白色椭圆和两小圆泡，分阶段出现 | 同样结构、展开顺序和时长，配色适配白龙娘 |
| 默认点击 | 角色打开第1项，气泡推进第2项，再点收起 | 额度 → 语录 → 收起 |
| 重复点角色 | 第1项续时，后续项回第1项 | 额度续时，语录回额度 |
| 自动收起 | 每项显示完成后5秒 | 5秒；点击续时 |
| 角色推进选项 | 可开启角色点击也推进 | 右键菜单可开启 |
| 语录 | 48句加权随机；第二项另有10:1机会选语录或petpet动图 | 20句原创加权随机，避免连续重复；第二项始终语录 |
| 编辑语录 | 内容、权重及更复杂序列、字体、模块设置 | 编辑内容与权重，恢复内置并备份旧列表；长句保持清晰字号，以摘要显示，悬停查看全文 |
| 音效 | 默认开启，按压/松开配对，短点击串联 | 默认开启、配对串联，可静音或调音量；使用自有合成音 |
| 拖动 | 3px后判拖动，拖动不点击 | 同样3px门限，丢失捕获取消点击 |
| 左右朝向 | 左侧镜像朝内，文字反向补偿 | 左侧朝内，文字保持可读；缩放在外层完成，镜像不改变气泡边界 |
| 缩放 | 连续滑杆与预设，保持角点 | 0.6–2.5滑杆与预设，边缘锚点保留 |
| 透明处 | 按图像alpha进行命中判断 | 读取alpha，透明像素不作为角色点击目标 |
| 菜单 | 悬浮按钮、右键、可隐藏按钮 | 同样支持；按功能分组，显示大小与音量，隐藏按钮同时关闭命中测试 |
| 额度数据 | DeepSeek余额/今日用量 | 读取 Codex 接口返回的 5 小时/每周额度，未返回的窗口不显示；数字和横条表示剩余，已用与重置时间可在悬停提示查看 |
| 窗口跟随 | 内嵌于DSH页面，自动随窗口，随主窗口被遮挡 | 外部WPF窗口，主窗口后台可见时仍显示；前后顺序跟随主窗口，随其他窗口遮挡；主窗口最小化、隐藏或关闭时隐藏，排除宠物mini |
| 客户端重开 | 页面插件随DSH主窗口加载 | 当前用户登录任务独立监测，重开Codex主窗口时自动补拉起；仅宠物mini不拉起 |
| 退出与停用 | 页面挂件设置与插件生命周期控制 | 退出一次保持到本轮主窗口关闭，手动打开可恢复；永久停用移除本挂件任务与插件登记，保留偏好 |

没有移植原版的动图导入、音频导入/切片、复杂任意气泡模块序列和触屏长按菜单。原版滚轮行为是把滚动交给下方页面，不是缩放；外部WPF窗口不能照搬页面DOM的滚动机制。本版用右键滑杆调整大小。

DSH 图片、动图与音效的使用范围和 MIT 代码授权不同，本版使用自有生成的白龙娘图及合成音。语录为原创本地列表，不调用模型。

此前的人工验证记录包括：9 项数据/刷新检查、8 组语录权重与回退检查、28 项声音序列与初始化检查，以及 WPF 展开与点击状态、5 秒续时、快速重开、alpha 命中、文字镜像补偿和剩余额度条检查。独立窗口测试收到 102 个移动事件，只能证明事件送达，不能证明完整客户端跟随过程完全无卡顿。这些数字是旧版验证记录，不是 1.2.4 的测试统计。

旧版自动显示模块另记录了 29 项独立检查，包含主窗口/mini 筛选、退出一次与窗口关闭后的恢复、窗口/进程编号重用、任务身份、电池与时限设置、重复原子写入、手动恢复及偏好保留。另记录了实际安装、额度读取及客户端重启检查。1.2.3 用原生所属窗口解决独立守护启动时挂件被主窗口压住的问题；独立窗口验证覆盖遮挡、顶层窗口、隐藏恢复及主窗口关闭后的清理。

1.2.4 的可重复检查位于 `tests/`，覆盖账号快照隔离、刷新队列、单实例额度进程、安装目录迁移、进程恢复和 WPF 布局。运行方法见[项目主页的开发与验证](../README.md#开发与验证)。自动化测试不能代替真实 Codex 客户端上的兼容性检查。
